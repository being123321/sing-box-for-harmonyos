# sing-box for HarmonyOS

非官方鸿蒙原生移植，界面参考 sing-box for Android。与 SagerNet 无官方关联。

- 稳定渠道：应用 **0.90.17**，上游正式内核 **1.14.4**。
- Beta 渠道：应用 **0.90.17-beta**，上游预发布内核 **1.15.0-alpha.13**。
- 渠道按上游内核区分，不能代表所有真机测试已经完成。
- 目标设备：Pura X / HarmonyOS 7.0.0.109；SDK API26，最低兼容 API22。
- 下载：[GitHub Releases](https://github.com/being123321/sing-box-for-harmonyos/releases)。HAP 未签名，需沿用原签名覆盖安装；不要卸载或清除数据。稳定版与 Beta 包名不同，分别保存数据。

## 本次更新

本次只发布最新 0.90.17；未发布的 0.90.15、0.90.16 不单独创建 Release，也不删除历史公开版本。以下汇总自 0.90.14 公开版本以来的最终改动。

- **二级页面恢复全屏透明叠放**：取消 0.90.15 的整页缩短视口；二级 Scroll/List 页面恢复全屏，内容可以经过透明页眉和悬浮导航/启动栏后方，末尾通过滚动内容内部的尾距让最后一项完整滑到控件上方。
- **固定操作区单独避让**：保存、完成等固定按钮所在区域单独保护，不再对所有页面统一裁去底部；配置选择等列表使用内容内末尾空项。
- **Clash 弹层与薄玻璃**：Clash 独立 `bindSheet` 只保留系统手势安全距离，不额外预留导航/启动栏高度；配置选择、分享、添加配置等主弹层使用更薄的原生玻璃材质。“减少透明效果”仍使用实色。
- **Tailscale 布局**：嵌入页面只渲染当前视图，支持父级传入顶部和底部距离，四类视图都有足够滚动范围；嵌入背景透明，独立模式保留原间距，修复下级视图重复显示和滚动空间不足。
- **滚动页顶部对齐（0.90.17）**：仪表盘项目、基础配置、添加配置、URL/DNS 和 Tailscale 等滚动视图统一顶部对齐，内容较少时不再居中导致页眉下大块留白。

保留 0.90.14 的网络恢复去重、配置校验复用和系统低内存异步回收，也保留 0.90.13 的即时模式/Clash 选择、导航立即切页和 0.90.11 的 VPN 前台恢复。

## 布局说明

0.90.16 起，页面本身不再缩短，滚动尾距放在内容内部。这样内容既能延伸到透明页眉和悬浮栏背后，又能在末尾留出足够空间。配置、节点、SSID、连接列表等 List 页面使用末尾空列表项；配置/节点编辑、主题、隐私、关于、来源、基础配置和导入等 Scroll 页面在内容内追加末尾距离。

固定保存/完成按钮单独避让，不随通用页面裁切。Tailscale 嵌入模式由父页面传入顶部和底部避让值，只显示一个当前视图；独立模式不叠加宿主间距。0.90.17 额外统一了内容较少页面的顶部对齐。

这些是 ArkUI 布局调整，不改变开关、节点、模式、VPN 恢复或内核行为。

## 使用

工具／设置 → 基础配置 → 节点选择，可通过链接、二维码、订阅、手动表单和 sing-box JSON 导入节点；模式选择支持 GFW 与大陆以外分流。也可直接导入自己的完整 sing-box JSON。策略组选择与仪表盘直连／规则／全局模式会持久化。

按需连接命中排除 SSID 时停止代理内核并释放 TUN，优先于分应用代理；手动测速不自动恢复 VPN。完整应用列表依赖获批的 GET_BUNDLE_INFO_PRIVILEGED 签名授权，普通签名不保证枚举全部应用。

WebRTC 禁用 STUN 在规则／全局模式拦截可识别的 UDP STUN；直连模式、SSID 挂起及排除应用保留直连语义。浏览器本地候选和系统 IPv6 接管需另外验证。
