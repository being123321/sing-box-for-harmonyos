# sing-box for HarmonyOS

非官方鸿蒙原生移植，界面参考 sing-box for Android。与 SagerNet 无官方关联。

- 稳定渠道：应用 **0.90.23**，上游正式内核 **1.14.4**。
- Beta 渠道：应用 **0.90.23-beta**，上游预发布内核 **1.15.0-alpha.13**。
- 版本代码均为 **1000132**。渠道由包内上游内核决定，不表示已经完成全部真机测试，也不表示本次更新了上游内核版本。
- 目标设备：Pura X / HarmonyOS 7.0.0.109；SDK API26，最低兼容 API22。
- 下载：[GitHub Releases](https://github.com/being123321/sing-box-for-harmonyos/releases)。
- HAP 未签名，升级须沿用原签名覆盖安装，不卸载、不清除数据。稳定版与 Beta 包名不同，分别保存数据。

## 本次更新

- **切网恢复**：跟随默认数据网络的 netId、承载、接口和地址集合；需要时重建 IPv6 VPN 路由，DNS 单独变化只重置连接，不再取消已建立的 TUN。网络未就绪、身份稳定等待和按需策略未知不消耗真实启动异常的重试预算。
- **按需判断**：Wi-Fi 关闭或默认承载为蜂窝时，不使用残留 Wi-Fi 关联判断排除 SSID；策略暂时未知时先保留可用的旧 TUN。沿用现有健康检查补查遗漏的网络事件，不增加独立高频轮询。
- **日志整体滚动**：标题、清空按钮、搜索框和日志卡片一起上滑；日志级别菜单到达状态栏下方后吸顶，向下滚回顶部恢复标题和搜索框。末尾日志可滚到浮动底栏上方。修正筛选后复用旧卡片的问题，并增加无匹配日志提示。
- **移除临时监测**：删除 Go/ETS VPN 诊断记录器、周期采样、复制诊断入口、材质能力调试日志，以及随源 USB 监测脚本和说明。保留正常日志、仪表统计、系统内存压力响应、VPN 健康检查、自动恢复、测速错误分类和 WebRTC 检测。
- **数据与材质**：保留配置、手动节点、模式和界面设置持久化，以及此前页眉、导航和二级页的透明玻璃实现。升级不自动恢复用户已删除的按需规则。

完整说明见 [0.90.23 更新说明](docs/RELEASE-0.90.23.md)。此前的 [0.90.10 更新说明](docs/releases/0.90.10.md) 仅作为历史记录；中间本地诊断版本不需要逐个发布。

## 验证范围

64 项相关 ETS、19 项原生 Go 顶层测试及 10 项相关 UI 测试通过；两个渠道均完成 HAP 编译、身份与版本、实际链接内核、包内原生库及 Deflate 压缩校验。这些是相关测试，不是全量测试通过声明。旧导航拖动测试有两项 fixture 缺少 selectNavigation 的历史失败，修改前源码也可复现。

当前手机仍为 0.90.21 Beta，新 0.90.23 尚未签名装机，日志滚动、SIM/4G/5G 切换和长期后台稳定性仍需复测。旧版在原 Wi-Fi、VPN 开启时实际 HTTPS 页面已能正常加载；HTTP 204 返回空白页面本身不代表故障，但该次成功也不能证明此前间歇性 Wi-Fi 故障已根治。不宣称彻底解决全部 VPN 掉线或 IPv6/WebRTC 泄漏。

## 使用与构建

可导入节点链接、二维码、订阅或完整 sing-box JSON。策略组选择、直连／规则／全局模式和配置数据会持久化。按需规则可分别选择挂起或直连；分应用代理读取完整应用列表仍依赖已获批的 GET_BUNDLE_INFO_PRIVILEGED 签名授权。

构建要求、渠道差异及验证步骤见 [BUILD-THIS-VERSION.md](BUILD-THIS-VERSION.md)，上游来源及本次二进制哈希见 [BUILD-MANIFEST.json](BUILD-MANIFEST.json)。两个渠道必须使用各自的源码和内核，不能互换。

所有 HAP 保留 module.json5 的 compressNativeLibs=true。签名前运行 `node scripts/verify-hap-compression.mjs <HAP路径> <本渠道stripped原生库路径>` 校验；压缩发生在签名前，不能重打包已签名 HAP。
