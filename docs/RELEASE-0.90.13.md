# 0.90.13

## 即时切换

- 仪表盘的直连、规则、全局点击后立即选中，不等内核命令确认，也不锁定整个界面。
- Clash API 策略组节点点击后立即高亮。后台串行提交命令，同一策略组连续点击时合并尚未发送的中间选择，优先呈现最后一次点击。
- 旧快照及旧命令回报不能覆盖较新的选择。命令成功后，等采样时间晚于确认时间的快照再交回实际状态；最新命令失败时提示并恢复最后已确认选择。
- 不再将节点延迟文字临时换成“切换中”，保持卡片文字布局及稳定键，避免文字替换引起跳动。
- 导航点击/滑动松手立即切页，取消 0.90.12 的 160ms 等待；只将滚动位置重置和数据轮询延后到异步任务。既有图标/文字动画保留。
- 用户停止或 VPN 会话改变后，丢弃旧选择队列及其迟到回报。异步执行不代表将 ArkUI 页面渲染移动到后台线程。

39 项相关测试通过，包括即时高亮、连续点击合并、旧快照隔离、旧请求失败不覆盖新选择、失败回退、会话重置、导航即时切换、VPN 恢复和 Tailscale 队列。

稳定及 Beta HAP 均构建成功，原生库内部 Deflate 压缩校验通过。版本代码 1000122，内核保持 1.14.4 / 1.15.0-alpha.13；保留包名、配置与节点存储。用原签名覆盖安装，不卸载、不清除数据。新切换交互尚待覆盖安装后的真机流畅度验证。

保留 0.90.11 的 VPN 恢复及底部滚动修复；0.90.11 的受控恢复真机记录见 RELEASE-0.90.12.md，不据此声称长期后台掉线已经完全解决。
