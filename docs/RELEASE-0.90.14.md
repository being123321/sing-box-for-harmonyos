# 0.90.14

## 网络恢复与内存压力

- IPv6 跨网络完整重建直接进入安全停止/重建路径，不再先对即将关闭的旧服务执行 ResetNetwork，减少一次无效连接及协程变更。IPv6 捕获和泄漏保护保持。
- 同一扩展生命周期内复用精确配置字符串的成功校验结果，恢复时避免重复创建临时校验实例。配置改变必须重新校验；失败、取消不缓存；扩展重建及最终清理时清空。真实内核启动仍验证、加载当前配置及资源。
- VPN 进程订阅系统环境内存通知，仅 LOW / CRITICAL / BACKGROUND_LOW / BACKGROUND_CRITICAL 请求异步 Go 空闲页回收。UI_HIDDEN 和 MODERATE 不触发，不添加周期 GC。
- 观察器合并压力通知；原生处理在 coreMu 下执行，全进程最多每 30 秒一次，服务重建不重置节流。仍使用 512 MiB Go 软目标；不修改系统回收评分或后台回收策略。
- 停止及扩展销毁取消未执行/迟到通知并安全注销订阅，不影响 TUN/内核正常清理。
- CMake 显式依赖新 Go 核心产物，避免缓存构建漏拷贝新内核。保留 0.90.13 即时模式/节点选择、导航以及底部滚动修复。

## 边界与回退

这次修复减少已确认的恢复冗余并响应系统内存压力，不能阻止系统强制终止，也不保证内存回调会先于终止执行。旧现场同时出现 KERN_ZONE_FREE_LOW，具体终止原因仍是未解读的 InvalidKillId，因此不能宣称已查明全部后台掉线原因或彻底根治。

稳定内核 1.14.4；Beta 内核 1.15.0-alpha.13。使用原签名覆盖安装，勿卸载或清除数据。回退源码基线为 98e5974e（0.90.13），旧 HAP 保留，原始日志和测试采样仅留本地 work/*private*，不可随源码或 Release 上传。
