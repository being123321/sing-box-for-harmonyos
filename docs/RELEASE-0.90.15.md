# 0.90.15

## 所有二级页面统一避让悬浮底栏

实际 build 主内容容器统一为所有非空 page 预留导航栏、启动栏和系统底部安全距离，再额外留 16vp。列表、Scroll、Web、TextArea 和固定完成/保存条均在同一安全视口内布局，避免仅给少数页面追加滚动尾距而遗漏其他页面。

覆盖配置列表和编辑、JSON 和节点编辑、节点导入、URL/扫码入口、基础配置、主题、WebRTC/隐私、按需连接及 SSID 编辑、分应用、连接列表、仪表盘项目、关于/开源地址、DNS 和 Tailscale 等实际页面路由。根导航页面保留原有透明叠放及滚动末尾余量，二级页面不再重复添加两份悬浮栏高度。

- 对没有自带页眉间距的页面补顶部避让；SSID 编辑不再出现在顶部避让之前。
- 仪表盘项目、基础配置、添加配置、URL 导入及 DNS 结果支持滚动。
- 节点复制弹层和配置选择列表按可用高度布局，列表可滚动；复制弹层长标题最多两行，保留取消按钮位置。
- Tailscale 嵌入模式进入详情、出口节点或 Taildrop 后只显示当前视图，避免同时渲染两个滚动视口、分摊高度。
- Clash 原生 bindSheet 是独立覆盖导航栏的弹层，不进入主页面避让容器；仍只保留其系统手势安全距离，不额外垫高导航/启动栏高度。

没有重新启用目前未挂入 build 的 drawerRootView；修复直接作用于用户实际看到的渲染路径。
