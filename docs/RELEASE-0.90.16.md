# 0.90.16

更正 0.90.15 二级页面统一缩短视口造成的上下截断和留白。主内容容器恢复全屏，滚动内容可以经过透明页眉及悬浮导航/启动栏后方；末尾保留足够滚动余量，让最后一项能完整滑到控件上方。

- 配置、节点、SSID、连接列表使用 List 内容内的末尾空项；配置/节点编辑、主题、隐私、关于、来源、基础配置和导入等 Scroll 页面在内容内部追加末尾距离。不是缩短 Scroll/List 本身。
- 主题页顶部避让移入滚动内容，避免滚动经过页眉时形成固定截断。
- JSON/节点文本编辑、WebRTC 和分应用等固定操作区单独保护保存、完成按钮，不再对所有页面统一裁去底部。
- 添加配置、URL、DNS 根页面在滚动内容内部处理顶部和末尾间距，共享原生添加配置弹层不额外添加导航栏高度。
- Tailscale 的嵌入页面支持父级传入顶部和底栏距离，四类视图尾部有足够滚动范围；嵌入背景透明，独立模式保留原间距。保留单一当前视图修复。
- 配置选择、分享、添加配置所用主弹层改为更薄的原生玻璃材质。减少透明效果选项仍使用实色背景。
- Clash 独立 bindSheet 保持自己的系统手势安全距离，不额外预留导航和启动栏高度。

13 项相关回归通过，稳定与 Beta HAP 构建、内部 Deflate 压缩和包内核心一致性校验通过。版本代码 1000125。核心保持 0.90.14 的改动，稳定为 1.14.4，Beta 为 1.15.0-alpha.13；VPN 及节点/配置行为不变。

0.90.15 在手机上确认了末尾内容和固定完成按钮避让，以及独立 Clash 弹层末尾可见；用户进一步指出其上下截断不符合透明叠放要求，本版修正该布局方式。0.90.16 新包尚需签名覆盖安装后的视觉验证，不能把 0.90.15 的有限检查算作本版已验证所有页面。

用原签名覆盖安装，勿卸载或清除数据；发布时以本版最终说明为准，跳过 0.90.15 中间包。原始布局、截图和日志只留本地，不上传。
