# 0.90.17

修正“仪表盘项目”等新增 Scroll 页面在内容较少时居中，导致页眉下大段留白、开关悬在页面中部的问题。仪表盘项目、基础配置、添加配置、URL/DNS 和 Tailscale 滚动视图统一顶部对齐，不变更开关、节点、模式或布局结构。

13 项相关回归通过。稳定、Beta 两个 HAP 构建与内部压缩检查通过，原生核心沿用 0.90.14：稳定 1.14.4 / Beta 1.15.0-alpha.13。版本代码 1000126。
