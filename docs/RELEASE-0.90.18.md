# 0.90.18 本地诊断测试版（暂不发布）

用户要求本版仅本地自测，不上传 GitHub 或分发给其他人；后续移除临时诊断。稳定内核仍为 1.14.4，Beta 内核仍为 1.15.0-alpha.13，通道由上游内核决定。版本代码 1000127。

## 网络修复

- ETS 网络签名和原生出站 socket 绑定统一跟随系统默认物理网络；不再优先 Wi-Fi 或最低 netId，避免双卡默认数据切换后继续绑定旧 SIM。
- 前后两次默认 netId 必须一致，网络必须有 INTERNET、NOT_VPN、VALIDATED 且不是 VPN；缺失、未验证或切换中的网络等待后续重试，不回退旧 SIM。
- 监听系统默认网络变化；短暂断开即使在防抖读取前恢复，也保留连接失效标记。
- 回到同一网络后清理失效连接；默认 netId、接口或地址发生变化时，IPv6 保护路径重建 TUN。DNS 单独变化或 IPv4 切换保留轻量重置。
- 信号强弱和无线制式变化本身不作为 TUN 重建依据。手动停止、SSID 挂起、其他 VPN 优先级和保存的节点选择保持有效。

## 临时诊断

- 应用内：复用现有健康检查，最多每 60 秒记录一次 Go 堆、上次 GC 后存活堆、已归还页、协程、GC 计数、进程 RSS/Swap/线程；切网、重建、启动/停止、系统内存通知等事件另行记录。
- 记录不强制 GC、不重启 VPN、不增加常驻采样线程或额外 ArkTS 定时器；写入失败不改变 VPN 状态。日志页新增“诊断”按钮，复制两个日志分段及应用/内核版本。
- `filesDir/runtime/vpn-diagnostic.jsonl` 与 `.1` 各不超过 256 KiB，总量约 512 KiB，自动轮转。不记录配置、订阅、节点名称/密码、IP、SSID 或连接域名。
- `goHeapLiveAfterLastGcBytes` 是最近一次 GC 后的存活堆，不能当成每次采样瞬时值；`assignedTunFd` 只表示内核保存的 fd，不证明系统 VPN 仍在。`observedVpnChannel` 是最近状态观测，也不是独立连续系统监测。
- 电脑端独立 USB 诊断脚本可交叉记录系统层状态。应用内记录日常使用不依赖 USB；PC 采集期间需要连接。两者都不能保证记录到 SIGKILL 的最后一刻。

## 界面

取消横贯页眉的玻璃底板和明显分界，标题及状态栏区域透明，仅操作按钮保留轻薄玻璃。保留此前所有二级页面的内部滚动尾距、透明叠放以及即时模式/节点选择。

相关 ETS 和原生专项检查、双通道交叉编译及 HAP 内部压缩校验见本地构建记录。本版尚需原签名覆盖安装后验证应用内记录和最终视觉效果；不卸载、不清除数据。
