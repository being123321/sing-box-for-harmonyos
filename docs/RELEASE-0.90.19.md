# 0.90.19 本地诊断测试版（暂不发布）

沿用用户要求的临时诊断，仅本人测试，不上传 GitHub。稳定内核 1.14.4 / Beta 内核 1.15.0-alpha.13，版本代码 1000128。原生内核二进制与 0.90.18 相同。

## 页眉

仪表、日志、工具、设置及共用 appToolbar 的二级页面统一样式：标题使用随文字宽度的 44 vp 高、14 vp 圆角玻璃底；操作按钮使用相同玻璃材质，右侧三点为原有 44 × 44 vp 区域。未增加工具/设置原本没有的菜单操作。

整条页眉与状态栏区域仍透明，不恢复整条椭圆底板或水平分界。材质与填充/边框放在独立背景层，避免 SDK 明确不建议的同组件样式混用；较明显的薄填充、模糊和边缘保底不依赖原生材质成功。导航栏、启动栏、滚动范围和模式/节点切换保持原行为。

## 诊断准确性

- 周期记录使用最近一次实际 VPN 探测结果，未知或过期观测记 unknown，不再用缓存 netId 推断 owned；恢复完成记录也使用实际结果。
- 正常运行中的 SSID 挂起在关闭资源之前标记。已初始化的原生记录器可在 service 停止后继续记录恢复时确认的策略挂起。
- 诊断忙时仍可能丢弃事件，onDestroy 的异步写入也不保证完成；没有该记录不能证明系统未调用回调。
- 首次启动就匹配挂起策略、尚未初始化 Go 的路径不会产生 Go 原生日志；这不表示代理已启动。

## 本地验证

71 项相关 ETS 测试通过，包含 unknown 不伪装成 owned、SSID 明确标记及关闭后记录。两通道 HAP 编译、包内新版本、既有原生库哈希及内部 Deflate 压缩校验通过；未重跑未改动的原生核心测试。全量旧测试未全部通过，限制见 0.90.18 说明。

手机已覆盖 0.90.18-beta 并确认扩展 PID 8111 与 TUN 工作，诊断按钮复制成功。通过应用内的 DNS 查询临时输入框读取到诊断文本，未执行 DNS 查询；输入框恢复 example.com，最终返回仪表盘，配置仍为 zh，未修改节点或模式。

导出的 02:56:40–03:10:52（2026-11-07，中国标准时间）共 17 条记录中，启动后 GC 存活堆约 9.5–12.1 MiB，末次约 9.5 MiB；协程末次 47，自动 GC 持续发生，强制 GC 计数未增加。末次 Go 管理且未归还内存约 30.7 MiB，进程 RSS 约 177.8 MiB。该约 14 分钟样本没有显示 Go 堆持续泄漏，不能排除其他负载、其他内存类别或更长时间的问题，也不能证明长期后台稳定。

0.90.19 的最终玻璃效果与修正后的诊断待原签名覆盖安装真机确认。原始诊断、布局、日志及 USB 记录仅在工程外 work 私有路径，不随源码归档或包分发。

## 省电审查（本版未改变）

既有后台统计已降低频率、使用轻量状态，内存回收没有周期性强制 GC。下一步可优化未使用 Tailscale 时每秒读取命令文件的空轮询，并按需初始化其管理客户端；不应删掉上游已有的事件订阅或削弱主 VPN 监督。节电幅度尚未测量。
