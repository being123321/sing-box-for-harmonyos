# 0.90.20 本地材质修正版（暂不发布）

根据用户对 0.90.19 真机效果的反馈，页眉材质改为导航栏选中项的同款实现。四个主页面及使用 appToolbar 的二级页面统一；标题和按钮保持紧凑，整条页眉、状态栏背景继续透明。

删除 toolbar 专用的白色填充、10 vp 模糊、自定义阴影和独立 material modifier，复用既有 `glassModifier(true)`、单 Tab 的 `Tabs → TabContent.tabBar()` 原生渲染路径、选中项的淡主题色 `#18accent` 以及 `0.5 vp / #33FFFFFF` 边缘。导航栏本身只将原有同值选中填色提取为共享函数，不改变布局、选择或拖动逻辑。

背景层不接收点击，避免挡住标题上的实际操作按钮；不能据此宣称触摸形变已经与可拖动导航项完全一致。0.90.20 的最终视觉效果仍待签名覆盖安装核对。

保留 0.90.19 的未知 VPN 状态/正常 SSID 挂起诊断修正，以及 0.90.18 的默认数据 SIM 绑定和网络恢复修复、临时应用内诊断与独立 USB 工具。未调整省电参数或弱化 VPN 监督。源码与数据仅本地保留，不上传 GitHub。

版本代码 1000129；稳定核心 1.14.4，Beta 核心 1.15.0-alpha.13，原生二进制与 0.90.18 相同。71 项相关 ETS 测试、双通道 HAP 编译、包内版本和原生库/内部 Deflate 压缩校验通过。全量旧测试未全部通过，既有诊断和测试限制见前版说明。

手机已确认安装并运行 0.90.19-beta，扩展 PID 26239，TUN 存在；实机截图中标题呈发白的圆角块，用户要求改成导航栏选中项材质，故本版更换渲染路径。未因这次界面检查切换配置、节点或网络。
