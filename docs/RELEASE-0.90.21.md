# 0.90.21 页眉原生透镜区域修正（仅本地测试）

0.90.20 的实机截图仍显示淡蓝半透明块，用户明确要求页眉的透镜玻璃。本版调整实际控件树，不再调整填充色来模拟透镜：真实标题 Stack、返回/三点/保存/诊断等 Button 一起放入实际 Tabs 的 TabBar 区域，材质直接应用到控件；删除 background Builder 中的装饰 Tabs 和外层裁切。收起按钮也归入同一区域。

依据 [华为组件适配沉浸光感说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-immersive-light-sense-component-adaptation/)，按钮和布局容器的原生材质有指定生效区域。此前背景装饰不等于真实操作控件位于该区域。本版改变符合该约束，但最终效果必须实机确认，不以编译通过代替视觉验收。

仪表、日志、工具、设置及使用 appToolbar 的二级页共用实现。保留透明整条页眉和状态栏，不把材质加到整个横向页眉；导航栏、配置、节点、VPN/按需逻辑和临时诊断均未改变。不修改全局 material metadata。

首次页面初始化增加一条不含隐私的 SfaUI 能力日志：是否支持系统材质、材质算力级别、应用材质状态、减少透明度开关。用于判断真机限制，不添加轮询。

版本代码 1000130。稳定核心 1.14.4，Beta 核心 1.15.0-alpha.13；原生二进制沿用 0.90.18。13 项相关 UI 测试、双 HAP 编译及包内版本/原生库/Deflate 压缩校验通过；新包尚未完成签名覆盖后的视觉与点击检查。全量旧测试未全部通过，限制见 0.90.18。
