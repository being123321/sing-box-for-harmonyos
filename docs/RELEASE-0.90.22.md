# 0.90.22 切网恢复与日志整体滚动（仅本地诊断测试）

本版针对切换默认数据 SIM、4G/5G 网络变化后 VPN 消失或反复重建的问题，修正物理网络识别、启动等待和自动恢复状态。版本代码为 1000131；稳定渠道使用 sing-box 1.14.4，Beta 渠道使用 1.15.0-alpha.13。渠道依据包内上游内核版本区分，不表示这两份内核为当前上游最新版本。

2026-11-07 读取的 0.90.21 持久化诊断中，多次出现网络重建、等待和重新启动；较晚的一段记录内 VPN Extension 进程保持不变，不能将每次 TUN 消失归因为进程被系统终止。用户确认纯蜂窝复现时 Wi-Fi 完全关闭。旧记录中的通用等待与 SSID 挂起存在混淆，不能仅凭旧的“挂起”文字断定命中了排除 SSID，也不能把整段诊断中的所有挂起事件都归为同一次蜂窝复现。

本版修正：

- 跟随当前默认数据网络，区分默认 SIM/netId、接口和地址集合变化。启用 IPv6 时，真实网络身份替换重建 VPN 路由；仅 DNS 变化或同一网络中断后恢复时使用连接重置。单纯信号强度、4G/5G 标记或地址顺序变化不触发 TUN 重建。
- 启动前后比较物理网络身份，不再因 DNS 单独变化取消已建立的 TUN。真正发生网络替换时安全等待，保留原配置、手动节点和模式选择。
- 正常的网络未就绪、身份稳定等待及按需信息暂不可读，不再消耗内核启动异常的重试次数。真实启动异常仍受次数、退避和冷却限制；手动停止始终优先。
- 在销毁可用的旧 TUN 前检查按需策略；策略未知时先等待。冷启动中策略未知也保留后台恢复路径，不要求重新打开应用。
- Wi-Fi 关闭或当前默认承载为蜂窝时，不使用残留 Wi-Fi 关联判断排除 SSID。读取关联后重新核对承载和身份，避免切换过程中的旧信息误触发挂起。
- 借用现有健康检查节奏补查物理网络身份，观察器正常时约 15 秒一次、未就绪时约 3 秒一次，补足遗漏事件；网络事件仍是主要响应路径。不增加独立高频定时器。
- VPN netId 改变、地址暂未分配或系统枚举不完整时，标记为所有权未知，而非直接认定另一 VPN。不会仅凭共用 TUN 地址接管连接，确认其他 VPN 时仍不抢占。若系统长期无法确认所有权，恢复仍可能停在等待状态，需要真机报告继续定位。
- 临时诊断分别记录网络不可用、身份变化等待、策略未知、DNS 稳定和 VPN 所有权等待，不写入 SSID、订阅或节点密码。

日志页改为单个原生 List：标题、诊断/清空按钮、搜索框和日志卡片一起滚动，级别筛选菜单使用 ListItemGroup Header 到达状态栏下方后吸顶；向下滚回顶部时重新显示标题和搜索。删除日志根页重复的全局固定页眉；其他主页面和二级页面仍保留原页眉。筛选菜单沿用原生玻璃材质，日志字体、搜索、筛选、清空、复制、诊断及底栏避让保留。不增加逐帧状态更新或嵌套滚动手势转交。此实现不是任意深度反向下滑即浮出标题的快速回显；签名覆盖后的滚动、点击和实机视觉验收仍待完成。

已完成 90 项相关 ETS 回归测试及 16 项原生 Go 顶层测试，覆盖默认 SIM 变化、IPv6 路由重建、DNS 变化、短暂断网、按需等待、重试预算、所有权不确定和手动停止等路径。合入日志交互后，双渠道 HAP 重新编译成功，最终包版本、实际链接内核、包内原生库及 Deflate 压缩校验通过。稳定包 26,796,080 字节，Beta 包 27,525,420 字节。另执行 14 项日志/导航/策略组/Tailscale UI 相关测试，其中 12 项通过、2 项旧导航拖动测试因 fixture 未装入 selectNavigation 而失败；用本次日志修改前的源码复跑，得到相同两项失败，未修改生产导航逻辑来规避此问题。旧全量测试并非全部通过，不将上述相关测试结果表述为全量通过。

当前手机安装的仍是 0.90.21 Beta，0.90.22 尚未在该手机签名覆盖安装，尚未验证真实 SIM/4G/5G 切换和长期后台稳定性。路由器 Wi-Fi 在正常代理模式下无法上网的问题也仍待取得实际请求错误日志，不认定与蜂窝问题同因或已修复。用户已删除的按需 SSID 规则不自动恢复。

保留 0.90.21 页眉原生透镜改动、配置和节点数据；覆盖安装须使用原签名，不卸载、不清数据。临时诊断继续仅供本地排查，原始报告存放于工程外的 work 私有文件，不进入公开源码或附件。本版未上传 GitHub，后续剔除临时诊断的要求继续有效。
