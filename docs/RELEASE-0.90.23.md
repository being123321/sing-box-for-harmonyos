# 0.90.23 切网恢复、日志滚动与临时监测移除

应用版本为 0.90.23 / 0.90.23-beta，versionCode 均为 1000132。稳定渠道使用正式内核 1.14.4，Beta 使用预发布内核 1.15.0-alpha.13；渠道按包内上游内核决定。本次保留这两个内核版本，不声称它们为当前上游最新版本。

## 改动

- 继承 0.90.22 的物理网络识别和恢复修复：按默认数据网络 netId、承载、接口及地址集合区分切换，DNS 单独变化不再取消已建立的 TUN。需要更新 IPv6 VPN 路由时才重建，单纯信号强度、4G/5G 标记或地址顺序变化不触发重建。
- 网络未就绪、身份稳定等待和按需策略未知不消耗真实内核启动异常的重试预算；真实启动失败仍有次数、退避和冷却限制。手动停止优先，恢复保留原配置、已选节点和模式。
- Wi-Fi 关闭或默认承载为蜂窝时，不使用残留 Wi-Fi 关联误判排除 SSID。销毁旧 TUN 前先核对按需策略，信息未知时保留可用旧连接；冷启动等待也保留后台恢复路径。使用现有健康检查节奏补查遗漏网络事件。
- VPN 枚举信息暂不完整、netId 改变或地址未就绪时，先等待所有权核实；不凭共享 TUN 地址接管其他 VPN。系统长期无法确认所有权时仍可能等待，需要实际场景继续验证。
- 日志页整体滚动：标题、清空按钮、搜索框和日志卡片一起上滑；级别菜单到状态栏下方后吸顶，向下滚回顶部恢复展开。末尾日志可滚到导航及运行栏上方，不增加逐帧状态切换或嵌套列表手势转交。
- 修复日志筛选后沿用旧卡片的问题，使用内容与索引共同标识卡片，重复日志仍可分别显示；筛选无结果时显示“没有匹配的日志”。
- 删除临时 Go/ETS VPN 诊断记录器、周期采样、复制诊断按钮、材质能力调试日志，以及随源 USB 监测脚本、测试和说明。保留普通日志、仪表统计、系统内存压力响应、VPN 健康检查和自动恢复、测速错误分类及 WebRTC 检测。
- 保留此前透明玻璃、配置及节点数据持久化。升级沿用原签名覆盖安装，不卸载、不清数据；不恢复已被用户删除的按需规则。

## 验证与限制

64 项相关 ETS、19 项原生 Go 顶层测试和 10 项相关 UI 测试通过；稳定与 Beta 均完成原生库重编译、HAP 编译、身份与版本、实际链接内核、包内原生库及 Deflate 压缩校验。未把相关测试表述为全量通过：旧导航拖动 fixture 缺少 selectNavigation 的两项失败在修改前也可复现。

当前手机仍为 0.90.21 Beta，新 0.90.23 尚未签名覆盖安装，日志滚动、真实 SIM/4G/5G 切换和长期后台稳定性均待真机复测。旧版在原 Wi-Fi 和 VPN 开启的场景下实际 HTTPS 页面已正常加载；HTTP 204 空白页面本身不是故障，但这次成功不能证明旧 Wi-Fi 间歇性故障已根治，也不能代替新版本验证。不宣称彻底解决全部 VPN 掉线或 IPv6/WebRTC 泄漏。

两包均在签名前压缩；完整与包内原生库、未签名 HAP 哈希见 BUILD-MANIFEST.json。签名后文件哈希会变化。当前仅完成本地构建，尚未上传 GitHub，交由维护者发布最新版本与匹配源码；不补发中间本地诊断版本，不上传签名材料、订阅或设备私有记录。
