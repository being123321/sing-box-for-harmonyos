# 0.90.24 保留 VPN 的网络与配置切换

本版参照 FlClash 鸿蒙分支的持有 VPN 与内核选择器思路，保留当前点击即选中的 UI；不是复制 Mihomo 实现。稳定内核仍为 1.14.4，Beta 仍为 1.15.0-alpha.13，versionCode 1000133。

- 网络事件：Wi-Fi/蜂窝、默认 SIM、接口或地址变化时保留已有系统 VPN 和 TUN，仅重置旧网络连接；DNS-only 变化只刷新内核解析/HTTP 缓存，不关闭全部连接。当前系统 TUN 地址和双栈默认路由固定，不依赖物理 SIM 地址；仍保留完整双栈接管。
- 策略组节点：界面立即选中，内核 selector 更新，随后刷新解析缓存；不重建 TUN/VPN。已有连接按 selector 的 interrupt_exist_connections 配置处理，不强制全局断开。
- 配置切换：界面立即选择新配置，私有加密候选文件传递配置，命令文件不含节点明文。先验证、应用每个配置保存的节点和模式；OS VPN 参数相同则只热加载内核，继续使用原 TUN。分应用范围或 VPN DNS 等实际系统参数改变时才重新建立 TUN。失败尝试恢复旧配置与模式，不将失败提前显示为成功。
- SSID 挂起：继续停止代理并释放 TUN，优先于分应用。挂起期间换配置只保存下次使用的配置，不擅自唤醒 VPN；离开后按原策略恢复。
- SSID 直连：继续经过内核并应用临时直连模式，切配置后重施直连，离开后恢复所选配置自己的模式。
- 真实系统 VPN 丢失、明确停止/启动及必要参数变化仍可重建。完整配置热加载仍可能分配新的内核资源，不代表零内存峰值或所有掉线已经根治。

61 项相关回归通过，包括 IPv6 跨网络/换 SIM 保留 TUN、DNS-only、断网返回、挂起与直连、热加载失败回退、手动停止及 VPN 参数改变路径。稳定/Beta 原生和 HAP 构建及实际库哈希、Deflate 压缩校验见 BUILD-MANIFEST.json。未宣称旧全量测试全部通过。新版尚未签名覆盖装机，SIM/4G/5G、IPv6/WebRTC 和长期后台仍需实测。
