# 0.90.25 更新说明

- 日志向上滚动固定级别菜单，向下滚动恢复标题；按需连接编辑区放在菜单下方。
- 配置和节点可通过左侧六点拖动排序，基础配置固定第一。节点左滑编辑、分享；长按多选，支持一次确认批量复制和统一编辑。
- 编辑节点可选同步删除其他配置同名节点；默认关闭，引用校验失败时整批取消。复制可选择同名覆盖及订阅更新保留。
- 设置新增“自动获取运营商 DNS”，默认关闭。仅替换本地/直连 DNS，代理 DNS 和保存的原始 JSON 保持原配置。开关改变热加载，网络提供的 DNS 改变动态刷新，不额外重建 TUN。
- 保留上一版网络切换优先保留 VPN/TUN、配置热加载、SSID 挂起/直连逻辑。临时监测已移除。

稳定内核 1.14.4，Beta 内核 1.15.0-alpha.13；渠道由上游内核决定。本次重编译包含本地动态 DNS 适配，未升级上游版本。

75 项相关回归、22 项 Go 策略测试、双渠道原生及 HAP 构建、库哈希与 Deflate 压缩校验通过。历史全量测试仍有未通过项。新版未签名装机，拖动手势、实际 DNS 转发及长期后台需要真机复测，不声称掉线或 WebRTC 问题已根治。

沿用原 HoKit 签名覆盖安装，不要卸载或清除数据。
