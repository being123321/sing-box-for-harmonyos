# 0.82 / 0.82 Beta

- 合并 PR #3：Tailscale 端点状态、登录入口、出口节点、ping 和 Taildrop 收件箱。
- 修复后台健康检查一次读取失败后停止自动监督的问题；下一次心跳继续检查，确认 VPN 丢失后按已有退避策略恢复，保留节点和模式。
- 修复保存模式与自定义配置 Rule/Global/Direct 拼写不一致的问题。
- 修正 Tailscale 停止期间的并发访问、排队请求过期、会话切换及状态文件并发写入。
- HAP 内部启用原生库压缩；发布校验要求大体积核心库确实压缩，后续版本延续此设置。

稳定包使用上游正式内核 **1.14.4**；Beta 包使用上游预发布内核 **1.15.0-alpha.13**。
“稳定/Beta”描述的是内核渠道，不代表所有功能已完成真机验证。

当前提供未签名 HAP，请用原来的 HoKit 签名身份覆盖安装。0.81 Beta 用户选择 **0.82-beta**；不要卸载或清除数据。稳定包和 Beta 包名不同，不能互相覆盖或自动共享配置。

25 项后台恢复、模式恢复和 Tailscale 命令队列测试通过；两渠道内核/HAP 构建及包结构、压缩和存储兼容性检查见随包 BUILD-MANIFEST。
完整工具测试仍有原基线失败，未宣称全绿。新版长时熄屏/切网、Tailscale 登录与 Taildrop 真机验证仍待完成；本版**不宣称彻底解决后台断联或 IPv6/WebRTC 泄漏**。

Taildrop 当前不支持发送，下载后的文件暂未提供打开/分享入口。完整应用列表仍需签名权限授权。
