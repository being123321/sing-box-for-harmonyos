# 0.83.1 / 0.83.1 Beta

## 修复启动失败

0.82 合并 Tailscale 后会在 VPN 扩展中绑定 `command.sock`，真机返回 `bind: permission denied`，导致内核初始化失败。本版改为仅进程内可访问的内存 RPC，不创建系统套接字文件或监听端口，也不申请额外权限。

同一修复已在 **0.83 Beta 真机**上确认：VPN 启动成功，停止后再次启动成功；工具页的 Tailscale 入口可打开。0.83.1 Beta 保留同一内核二进制，新增下面的界面调整。长时后台、切网、IPv6/WebRTC仍未宣称完全解决。

## Tailscale 窗口

- 工具页常驻显示入口，没有端点时给出配置提示，不再无限加载。
- 参照安卓版 sing-box 的端点页面，保留状态、本机、出口节点、Taildrop和设备列表分组。
- “打开认证链接”真正打开浏览器；增加“显示认证二维码”窗口和“复制认证链接”。状态与主要操作使用中文。
- 没有 Tailscale 端点的普通代理配置不会自动生成 Tailscale 设备；需先在配置中添加端点再启动。实际账号登录、出口节点和 Taildrop操作仍需对应配置实测，不能将普通代理启动成功视为这些功能全部通过。

## 包与检查

- 稳定渠道：sing-box **1.14.4**；Beta渠道：**1.15.0-alpha.13**。渠道跟随上游内核状态。
- 两种 HAP 均保留内部原生库压缩和配置/节点选择的存储兼容。
- 34 项相关测试通过；两个内核分支各3项真实内存RPC集成测试通过。两种HAP编译、版本、压缩、存储兼容及ZIP完整性检查通过。完整旧工具套件仍存在基线失败，不宣称全绿。
- 0.83.1新增认证窗口尚需用户配置对应端点后的真机验证；既有0.83 Beta启动测试不冒充0.83.1所有界面验证。

HAP未签名。当前0.83 Beta用户请选择 **0.83.1 Beta**，沿用原HoKit签名覆盖安装，不卸载、不清数据。稳定版与Beta包名不同，不能互相覆盖或自动迁移配置。
