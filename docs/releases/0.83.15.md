# 0.83.15

## 界面：页眉、导航栏回到 0.83 的薄膜材质

0.83.10 起试过用鸿蒙原生沉浸材质（`uiMaterial.systemMaterial`）绘制页眉和导航栏，真机上是发白的板子，还吃掉了滑动手势。本版整体回退到 0.83 的做法：全宽 `backgroundEffect` 薄膜（radius 20、saturation 1.35，深色 `#301C1D21`、浅色 `#18FFFFFF`），页眉无边框、导航栏 0.8 白边加投影、运行栏圆角 22。

- 保留 80% 的悬浮尺寸（导航 `72*0.8`、运行栏 `56*0.8`）。
- 选中胶囊加高到覆盖图标**和**文字，内部有一层 `radialGradient` 柔光在胶囊里来回流转（2.4s 单程、`EaseInOut` 交替），并继续跟手滑动；松手落点即所选菜单。
- “减少透明效果”开启时不渲染柔光、不做模糊。

## 订阅流量：按 Clash Meta 的实现对齐

参考 `MetaCubeX/ClashMetaForAndroid` 与 mihomo `adapter/provider/subscription_info.go`：

- 读 `subscription-userinfo` 响应头，`upload/download/total` 为字节、`expire` 为 Unix 秒；解析前转小写去空格，字段名大小写不敏感，单个字段非法只跳过该字段。
- 显示 `已用/总量`（1024 进制、两位小数 GiB）、进度条、`套餐到期：yyyy-MM-dd HH:mm:ss`。
- `total=0` 不再当作“不限量”；`expire=0` 不再显示“长期有效”；没有任何流量字段时整块不渲染。进度条只在 `total >= 2` 时出现。
- 从策略组名称提取“剩余流量”的逻辑降为次级兜底，只补剩余/到期两行，`已用/总量` 与进度条只由响应头驱动。

## 修复：启动失败 unknown clash mode

`sing-box-mobile-with-home` 这类本地配置里 `clash_api.default_mode` 写作 `Rule`，而应用保存的模式是小写规范值 `rule`；核心的 Go 桥用逐字节比较，判定为未知模式并把整个启动回滚。本版在恢复模式前先按配置里的真实拼写解析（`route.rules`、`dns.rules` 的 `clash_mode` 与 `clash_api.default_mode`），解析不到就跳过该指令，不再因为一条模式指令中断整个 VPN 启动。
