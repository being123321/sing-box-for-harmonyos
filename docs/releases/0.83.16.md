# 0.83.16

## 路由与按需连接

- 直连和全局继续经过 TUN 与内核。运行时将明确的 reject／旧 block 出站规则放在模式兜底规则之前，并保留嗅探和 DNS 劫持准备步骤；配置生成器也保留两种模式下的本地及导入阻止规则。
- DNS 明确 reject 规则优先于模式上游选择；带 evaluate/respond 的 DNS 程序保留原顺序，避免破坏依赖。
- 不新增广告规则来源，不修改保存的原始 JSON。规则自身的条件（包括显式模式限制）保持不变；动态 selector 不能等同于固定阻止规则。
- 按需连接增加匹配 SSID 后的“挂起／直连”选项。默认保持旧版挂起行为：关闭内核和 VPN；直连行为则保留内核及 VPN，临时切换直连模式，继续处理配置已有的过滤规则。
- 离开匹配 SSID 后恢复之前模式。临时直连不写入节点／模式选择记录；策略生效期间拒绝手动模式覆盖，切换节点仍可用。未知 SSID 保持现状。
- 同一排除列表共用行为设置；尚未提供逐 SSID 独立行为。

## 导航栏

- 流光改为可重新启动的往返动画；页面重新出现或回到前台后续播，离开页面或退后台时停止计时。
- 选中菜单图标放大 8%，文字放大 6%；保留现有材质、布局与滑动选择行为。
