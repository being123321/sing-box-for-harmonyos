# 0.83.19：菜单抽屉与配置节点操作

## 菜单

- 工具与设置使用同一列表内的向下抽屉，替代切换整个内容页。展开后菜单标题在外层 ListItemGroup 中吸附；到达页眉后限制外层继续向前滚动，由嵌套内容滚动，标题保留“收起”。收起、返回父菜单仍可操作。
- 工具 → 配置 → 基础配置／自定义配置。基础配置下展开节点与模式选择；配置编辑、完整 JSON、节点编辑、导入等留在配置抽屉中。
- 配置选择、添加配置、URL 导入、策略组与 SSID 编辑由原有弹层改为当前抽屉内容。确认保存／覆盖的对话框以及系统扫描器、文件选择器和外部登录仍使用各自交互。
- Tailscale 原页面提取为可嵌入的功能组件，保留端点、Peer、Exit Node、Taildrop 等功能，子视图在端点内容下方展开；旧路由入口保留兼容。轮询只在组件存活且应用处于前台时运行。

## 节点与覆盖

- 长按配置进入选择，同时在对应配置右侧显示“节点”；点击后向下展开节点列表，各节点有编辑按钮。
- 自定义配置节点用完整出站 JSON 编辑，不经过 URI 有损转换；保留 tag，避免破坏策略组引用。覆盖原节点、另存为独立本地节点配置、取消三种选择明确区分。
- 拖动节点到另一个配置条目表示复制；目标有拖入高亮和“已接收”反馈。相同内容及依赖的节点不重复写入；同名内容不同则选择覆盖或保留两份，后者追加后缀。
- 自定义配置间复制保留出站／DNS 依赖，冲突依赖标识重命名并更新引用；复制节点加入目标主要 selector，不改变既有 selector 默认选择或 route.final。没有 selector 的原始配置保留其原路由，需要在 JSON 中引用新增节点。
- 基础配置使用现有 URI 节点目录：已有基础节点沿用原 URI，其他节点仅在现有转换器可完整表达时导入；遇到无法无损表示的参数／链式依赖会拒绝并提示，不静默丢参数。其余自定义配置间保持完整 JSON。
- 节点另存为独立配置时名称冲突会加后缀。编辑现有配置亦提供覆盖／另存；改名或新建遇到其他配置同名时加后缀。
- 手动替换基础订阅节点保留其订阅归属，订阅更新按远端内容覆盖；显式另存的本地节点独立保留。
- 更新完整配置可取消、更新覆盖、先另存当前内容再更新；最后一种在同一次加密目录保存中完成。目标配置在确认期间发生变化会拒绝覆盖，要求重新操作。
- 复制不删除源节点。自定义配置编辑／复制不会自动替换运行中的服务，重启后应用；基础配置仍沿用其既有重建机制。

## 下载动画

- 启动后悬浮控制区增加从左向右移动的红色渐变圆点与拖尾，波形幅度由真实下载速率决定。零流量为水平线；挂起、停止或退到后台停止动画，不构造保活流量。
