# 0.83 真机验证包

- 修复0.82在VPN扩展初始化时创建command.sock被系统拒绝、导致VPN无法启动的回归。Tailscale通信改为仅进程内可访问的内存连接，不创建系统套接字文件或监听端口。
- 工具页常驻显示Tailscale入口；未运行或未配置端点时提供说明，不再无限显示加载中。自动选择首个端点，端点消失时清空旧详情。
- 保留0.82的后台恢复修复、模式/节点持久化和HAP原生库压缩。

稳定内核1.14.4，Beta内核1.15.0-alpha.13；包版本码1000083。0.82 Beta用户选择0.83 Beta，以原HoKit签名覆盖安装，不卸载、不清数据。

32项相关测试通过，两个内核/HAP均已构建；稳定内核分支的3项内存RPC原生集成测试通过，包含不可创建套接字路径的真实RPC连接、客户端独立生命周期与断连后不可重连。签名包真机启动仍需完成，验证完成前不宣称已解决所有启动/后台问题。IPv6/WebRTC长时验证仍未完成。
