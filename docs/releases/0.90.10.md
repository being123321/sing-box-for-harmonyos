# 0.90.10 / 0.90.10 Beta

本次只发布最新 0.90.10；0.90.6、0.90.7、0.90.8、0.90.9 未单独发布，以下汇总自 0.90.5 公开版本以来的最终改动。稳定版 0.90.10 使用 sing-box 1.14.4，Beta 版 0.90.10-beta 使用 1.15.0-alpha.13；两渠道 versionCode 均为 1000119。

## 后台快照精简（0.90.6）

- VPN 扩展仅在 UI 活动租约有效（前台）时生成 Tailscale 界面状态快照。退到后台后不再调用 `nativeCore.tailscaleStatus()`，也不再写 `tailscale-status.json`。
- 快照原先随后台 3 秒心跳触发，理论上最多约 1200 次/小时；这是调用次数估算，不是实测耗电或内存数据。
- Tailscale 实际连接、显式命令、VPN 心跳、内核健康检查、切网和断线恢复策略不变；回到前台后恢复快照刷新。该优化不构成“彻底修复 VPN 掉线”的结论。

## 透明玻璃、状态栏与运行栏（0.90.7-0.90.9）

- 页面、页眉、导航和运行栏使用更透明的薄烟灰玻璃。原生沉浸材质可用时，不再叠加 40% 底色和额外 12vp 背景模糊，改用 3%/6% 低透明底色；能力较低时使用 6vp 轻薄模糊后备，“减少透明效果”仍切换为实色。
- 导航选中底色改为淡色透明高光，保留选中图标/文字 10% 放大、滑动选择和原生交互形变；光效改为中性高光。全宽页眉不再叠加外框和阴影。
- 页眉玻璃覆盖“状态栏高度 + 64vp 工具栏”整个区域，内容仍位于状态栏下方，避免状态栏与页眉材质断层。
- 底部导航整体下移 6.4vp，仍保留系统底部手势安全区。运行栏相对 0.90.7 放大 120%，约为最初尺寸的 84%；在仪表盘上以 84% 宽度显示，宽度、高度、字号、图标、间距和圆角按同一比例调整。
- 取消仪表盘为浮动栏缩短滚动视口的处理，也取消页面为底部导航预留的额外大块空间；内容恢复到浮动导航和运行栏背后延伸。
- 以上只调整 ArkUI 视觉和布局，不修改内核二进制，不声称与参考录像逐像素一致。

## 节点选择卡顿优化（0.90.10）

- Clash 策略组卡片身份不再包含当前选择和所有节点延迟，选择或延迟刷新时不会销毁重建整张卡片及展开网格；节点列表结构变化时仍正确刷新。
- 选中状态和延迟通过独立 Map 更新；相同快照不重复更新展示状态。
- 点击后立即显示“切换中”，已有选择或正在处理时不重复提交；失败保留已确认的选择，不提前显示成功。
- 手动选择时不再继续派发本轮剩余的自动测速请求；已经在核心开始的测速不强制中断，也不重启 VPN 或内核。
- 该改动不改变 sing-box 内核、网络栈、路由配置或数据存储。实际设备帧率、选择耗时仍待复测，不宣称消除所有卡顿。

## 内核与验证

- 完成 v2rayH VPN 生命周期和内核源码对照，固定审查提交 `cc6cd53388bf707a980a66f1f4551b37eb487d3e`；没有复制对方实现，没有更换网络栈或修改内核二进制。报告见 [VPN 生命周期对照](../V2RAYH-VPN-REVIEW-2026-11-06.md) 和 [内核源码对照](../V2RAYH-CORE-COMPARISON-2026-11-06.md)。
- 26 项展示状态、真实选择处理、自动测速批次、节点保留及 VPN 恢复相关测试通过；两渠道 HAP 编译、身份/版本、原生库 Deflate 压缩和 ZIP 完整性检查通过。
- 完整工具测试仍有历史失败，本次没有对新版本做签名装机长期测试。系统终止扩展进程仍可能造成掉线，不宣称彻底修复 VPN 断联或 IPv6/WebRTC 泄漏。

## 发布与校验

- 只提供最新 0.90.10 与 0.90.10-beta，不补建 0.90.6-0.90.9 的 Release，也不删除历史公开版本。
- 每个渠道附完整对应源码 ZIP、BUILD-MANIFEST.json 和 SHA256SUMS；SHA256 以 Release 中的校验文件为准。
- HAP 未签名，需沿用原签名覆盖安装；稳定版与 Beta 包名不同，不要卸载或清除数据。
