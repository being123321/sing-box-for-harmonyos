# 0.90.13 / 0.90.13 Beta

本次只发布最新 0.90.13；0.90.11、0.90.12 未单独发布，以下汇总自 0.90.10 公开版本以来的最终改动。稳定版 0.90.13 使用 sing-box 1.14.4，Beta 版 0.90.13-beta 使用 1.15.0-alpha.13；两渠道 versionCode 均为 1000122。

## VPN 前台恢复（0.90.11）

- 意外停止 VPN 不再把用户的连接意愿改为关闭；重新进入前台后，同时检查失效运行会话和已经清理的停止会话。
- 自动恢复发送的停止命令带 `foreground-recovery` 来源标记，失败后允许再次检查；用户主动停止仍禁止自动重连。
- 已取得同会话内核/TUN 清理确认、但系统扩展已经退出时，只有连续完整网络清单确认没有 VPN，才允许完成停止确认。未确认清理的陈旧运行会话仍需原有的系统停止、VPN 消失和文件锁校验；未知或仍存在 VPN 时失败关闭。
- VPN 状态轮询只读取 Tailscale 缓存，不再等待最长 15 秒的端点命令响应。
- 心跳不可确认时不继续把缓存状态标记为健康连接。系统已清除整个扩展时，扩展内定时器无法自行运行；本版只保证前台恢复，不承诺后台自启动。

## 底部内容避让（0.90.11）

- 仪表盘、配置等滚动内容按悬浮控件实际高度增加末尾滚动余量，最后一项可以滚动到导航栏和启动栏上方，不再被底部导航遮挡。
- 该处理针对滚动页面；不能据此声称所有子页面、字体缩放和横竖屏组合均已逐一验证。

## 模式与 Clash 节点即时高亮（0.90.13）

- 直连、规则、全局点击后立即选中，不等内核命令确认，也不锁定整个界面；Clash API 策略组节点点击后立即高亮。
- 后台按选择器串行提交命令；同一策略组连续点击时合并尚未发送的中间选择，优先呈现最后一次点击。
- 旧快照及旧命令回报不能覆盖较新的选择。命令成功后，等采样时间晚于确认时间的快照再交回实际状态；最新命令失败时提示并恢复最后已确认选择。
- 不再把节点延迟文字临时替换成“切换中”，保持卡片文字布局和稳定键，避免文字替换引起跳动。
- 用户停止 VPN 或会话改变后，丢弃旧选择队列及其迟到回报。异步执行不代表将 ArkUI 页面渲染移动到后台线程。

## 导航立即切页（0.90.13）

- 导航点击或滑动松手立即切页，取消 0.90.12 的 160ms 等待；只将滚动位置重置和数据轮询延后到异步任务。
- 保留既有图标/文字动画。返回、退到后台或页面销毁会取消尚未执行的滚动复位/轮询；已运行的 VPN 不停止。

## 验证与安装

- 39 项相关测试通过，包括即时高亮、连续点击合并、旧快照隔离、旧请求失败不覆盖新选择、失败回退、会话重置、导航即时切换、VPN 恢复和 Tailscale 队列。
- 稳定及 Beta HAP 均构建成功，原生库内部 Deflate 压缩校验通过。versionCode 1000122，内核保持 1.14.4 / 1.15.0-alpha.13；保留包名、配置与节点存储。
- HAP 未签名，需用原签名覆盖安装，不卸载、不清除数据；稳定版与 Beta 包名不同。
- 新切换交互尚待签名覆盖安装后的真机流畅度验证；长期后台稳定性也未确认，不宣称彻底解决 VPN 掉线或 IPv6/WebRTC 泄漏。

## 发布与校验

- 只提供最新 0.90.13 与 0.90.13-beta，不补建 0.90.11、0.90.12 的 Release，也不删除历史公开版本。
- 每个渠道附完整对应源码 ZIP、BUILD-MANIFEST.json 和 SHA256SUMS；SHA256 以 Release 中的校验文件为准。
