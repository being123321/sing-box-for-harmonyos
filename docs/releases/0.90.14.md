# 0.90.14 / 0.90.14 Beta

本次只发布最新 0.90.14，不补建中间版本，也不删除历史公开版本。以下汇总自 0.90.13 公开版本以来的最终改动。稳定版 0.90.14 使用 sing-box 1.14.4，Beta 版 0.90.14-beta 使用 1.15.0-alpha.13；两渠道 versionCode 均为 1000123。

## 网络恢复去重（0.90.14）

- IPv6 跨网络完整重建直接进入安全停止/重建路径，不再先对即将关闭的旧服务执行 ResetNetwork，减少一次无效连接及协程变更。
- IPv6 捕获和泄漏保护保留；不以移除路由保护换取表面不断线。
- 同一 VPN 扩展生命周期内复用精确配置字符串的成功校验结果，恢复时避免重复创建临时校验实例。
- 配置改变必须重新校验；失败、取消不缓存；扩展重建及最终清理时清空。真实内核启动仍验证、加载当前配置及资源。

## 系统低内存异步回收（0.90.14）

- VPN 进程订阅系统环境内存通知，仅 LOW / CRITICAL / BACKGROUND_LOW / BACKGROUND_CRITICAL 请求异步 Go 空闲页回收。UI_HIDDEN 和 MODERATE 不触发，不添加周期 GC。
- 观察器合并压力通知；原生处理在 `coreMu` 下执行，全进程最多每 30 秒一次，服务重建不重置节流。
- 仍使用 512 MiB Go 软目标；不修改系统回收评分、后台回收策略或整个进程 RSS 上限。
- 停止及扩展销毁取消未执行/迟到通知并安全注销订阅，不影响 TUN/内核正常清理。

## 构建与内核对应

- CMake 显式依赖新的 Go 核心产物（`LINK_DEPENDS`），避免缓存构建漏拷贝新内核。
- 稳定和 Beta OHOS arm64 原生核心均重新交叉编译，tags 包含 `with_tailscale`；未更新各自上游版本或依赖。
- 已逐段比对构建核心、CMake 拷贝及打包前 strip 产物；HAP 内核心哈希与对应 strip 产物一致。
- 未 strip 核心 SHA256：稳定 `1909e7072e53e34f4832c961affe472950e7ff90411f15f048b05a388b29563b`，Beta `114452da6c1f681a47f70da574a913ce76c522c442784fd327d22fcb27a7535d`。
- HAP 内 strip 核心 SHA256：稳定 `9917db14d288eef0790c9c6e2c4e30e8a1829f62d229ef724e5628ca9cacd153`，Beta `3965ea161d7a55159086d2f86d0af146eddf07e2fbbcee2af7fea9a2e60db7d6`。

## 边界与回退

- 这次修复减少已确认的恢复冗余并响应系统内存压力，不能阻止系统强制终止。旧现场同时出现 `KERN_ZONE_FREE_LOW`，具体终止原因仍是未解读的 `InvalidKillId`，不能宣称已查明全部后台掉线原因或彻底根治。
- 保留 0.90.13 的即时模式/Clash 选择、导航和底部滚动修复；保留 0.90.11 的 VPN 前台恢复。
- 稳定内核 1.14.4；Beta 内核 1.15.0-alpha.13。HAP 未签名，需用原签名覆盖安装，勿卸载或清除数据；稳定版与 Beta 包名不同。
- 原始日志、落盘压缩日志、布局和内存采样仅留在本地 `work` 的 private 文件，不随源码或 Release 上传。
