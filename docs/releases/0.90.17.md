# 0.90.17 / 0.90.17 Beta

本次只发布最新 0.90.17；0.90.15、0.90.16 未单独发布，不删除历史公开版本。以下汇总自 0.90.14 公开版本以来的最终改动。稳定版 0.90.17 使用 sing-box 1.14.4，Beta 版 0.90.17-beta 使用 1.15.0-alpha.13；两渠道 versionCode 均为 1000126。

## 二级页面全屏透明叠放（0.90.16）

- 取消 0.90.15 对所有二级页面统一缩短视口的处理。页面恢复全屏，Scroll/List 内容可以经过透明页眉和悬浮导航/启动栏后方。
- 末尾避让放在滚动内容内部：配置、节点、SSID、连接列表等 List 页面增加末尾空项；配置/节点编辑、主题、隐私、关于、来源、基础配置、导入等 Scroll 页面在内容内追加末尾距离。不是缩短 Scroll/List 本身。
- 主题页顶部避让移入滚动内容，避免滚动经过页眉时形成固定截断。
- 仪表盘项目、基础配置、添加配置、URL/DNS 和 Tailscale 等滚动视图统一顶部对齐，内容较少时不再居中造成页眉下大块留白。

## 固定按钮与弹层

- JSON/节点文本编辑、WebRTC 和分应用等固定操作区单独保护保存、完成按钮，不再对所有页面统一裁去底部。
- 添加配置、URL、DNS 根页面在滚动内容内部处理顶部和末尾间距；共享原生添加配置弹层不额外添加导航栏高度。
- Clash 独立 `bindSheet` 只保留自己的系统手势安全距离，不额外预留导航和启动栏高度。
- 配置选择、分享、添加配置所用主弹层改为更薄的原生玻璃材质；“减少透明效果”仍使用实色背景。

## Tailscale 布局

- Tailscale 嵌入页面支持父级传入顶部和底部距离，四类视图尾部有足够滚动范围。
- 嵌入背景透明，独立模式保留原间距；只渲染当前视图，修复下级视图重复显示和滚动空间问题。

## 保留的既有修复

- 保留 0.90.14 的 IPv6 跨网络重建去重、精确配置校验复用和系统低内存异步回收。
- 保留 0.90.13 的即时模式/Clash 节点选择、连续点击合并、旧回报隔离、失败回退和导航立即切页。
- 保留 0.90.11 的 VPN 前台恢复和底部滚动避让。

## 构建与内核对应

- 稳定和 Beta 原生核心沿用 0.90.14，未替换内核或上游依赖。
- HAP 内 strip 核心 SHA256：稳定 `9917db14d288eef0790c9c6e2c4e30e8a1829f62d229ef724e5628ca9cacd153`，Beta `3965ea161d7a55159086d2f86d0af146eddf07e2fbbcee2af7fea9a2e60db7d6`。
- 两个 HAP 构建成功、versionCode 1000126，原生库内部 Deflate 压缩校验通过。

## 验证与安装

- 13 项相关布局/视图回归通过。完整工具测试仍有历史失败，不宣称全部测试通过。
- 真机记录：0.90.16 的配置列表已能看到列表经过透明导航栏后方；检查期间自动点击曾误选另一配置，随后确认恢复 zh 且 TUN/内核运行。0.90.15 的分应用固定完成按钮和独立 Clash 弹层末项可见检查，不代表本版所有页面均已逐项验证。
- 0.90.16 的“仪表盘项目”截图显示较大顶部留白，本版增加显式顶部对齐；0.90.17 最终视觉效果尚待签名覆盖安装后确认。
- 长期后台稳定性、所有切网场景和所有字体/横竖屏组合未确认，不宣称彻底解决后台掉线或所有布局问题。
- HAP 未签名，需用原签名覆盖安装，勿卸载或清除数据；稳定版与 Beta 包名不同，不能互相覆盖。
- 原始布局、截图、日志和用户配置仅留本地，不随源码或 Release 上传。

## 发布与校验

- 只提供最新 0.90.17 与 0.90.17-beta，不补建 0.90.15、0.90.16 的 Release，也不删除历史公开版本。
