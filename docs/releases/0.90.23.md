# 0.90.23 / 0.90.23 Beta

本次只发布最新 0.90.23 稳定渠道与 0.90.23-beta 测试渠道；0.90.18 至 0.90.22 为本地诊断/测试版本，不单独创建 Release，也不删除已有公开版本。以下汇总自上次公开版本 0.90.17 以来的最终改动。

稳定版 0.90.23 使用 sing-box 1.14.4，包名 `com.harmonynet.assistant`；Beta 版 0.90.23-beta 使用 1.15.0-alpha.13，包名 `com.harmonynet.assistant.beta`。两渠道 versionCode 均为 1000132。渠道由包内上游内核决定；本次没有把这些内核称为上游最新版本。

## 切网恢复

- 跟随系统当前默认数据网络，使用 netId、承载、接口和地址集合识别切换；默认 SIM、4G/5G 标记和地址顺序变化不再错误沿用旧网络。
- DNS 单独变化或同一网络短暂中断后恢复，使用连接重置而非丢弃已建立的 TUN；真实 IPv6 路由身份替换时才重建 VPN。
- 网络未就绪、身份稳定等待和按需策略未知不消耗真实内核启动异常的重试预算；真实启动失败仍受次数、退避和冷却限制。
- 手动停止始终优先；自动恢复保留原配置、已选节点和模式。Wi-Fi 关闭或默认承载为蜂窝时，不使用残留 Wi-Fi 关联判断排除 SSID。
- 在销毁可用旧 TUN 前核对按需策略；信息未知时先保留连接。冷启动策略未知仍保留后台恢复路径。VPN 枚举不完整、netId 改变或地址未就绪时先等待所有权核实，不凭共享 TUN 地址接管其他 VPN。
- 沿用现有健康检查节奏补查遗漏网络事件；事件仍是主要响应路径，不增加独立高频轮询。

## 日志页

- 日志标题、清空、搜索框和卡片处于同一个原生 List，一起滚动；级别菜单到达状态栏下方后吸顶，滚回顶部恢复标题和搜索。
- 末尾日志可滚到悬浮导航及运行栏上方；不增加逐帧状态切换或嵌套列表手势转交。
- 修复筛选后沿用旧卡片的问题：卡片 key 结合内容与索引，重复日志可分别显示；无匹配结果时显示“没有匹配的日志”。

## 移除临时监测

删除临时 Go/ETS VPN 诊断记录器、周期采样、复制诊断入口、材质能力调试日志，以及随源 USB 监测脚本和说明。保留普通日志、仪表统计、系统内存压力响应、VPN 健康检查与自动恢复、测速错误分类和 WebRTC 检测。

## 自 0.90.17 以来的中间修正

- 0.90.18 至 0.90.22 逐步修正默认数据 SIM 绑定、物理网络签名、IPv6 路由重建、按需等待、启动重试预算和 VPN 所有权判断。
- 0.90.19 至 0.90.21 调整页眉玻璃与原生透镜区域；0.90.20 复用导航选中项材质，0.90.21 将真实标题和操作按钮放入原生 TabBar 区域。最终页眉、透明状态栏和二级页面叠放保留。
- 0.90.22 引入日志整体滚动与吸顶筛选菜单；0.90.23 完成筛选卡片身份修复和临时诊断清理。
- 中间诊断包仅用于本地排查，不作为公开版本发布。

## 内核与构建

- 稳定和 Beta 原生核心均重新编译；HAP 内 strip 核心 SHA256：稳定 `a782f2e222aa3758f5c889698b3385abc26db0605a88ec37191012d615a7b8a6`，Beta `dc77164f54f0c06f576e3e8c4483c1085398934b41ef642fd87bca041f01c34a`。
- 未 strip 核心、包内库和未签名 HAP 哈希见 BUILD-MANIFEST.json；签名后 HAP 哈希会变化。
- 两个 HAP 均为未签名 Release 包，原生库已 Deflate 压缩。

## 验证与限制

- 64 项相关 ETS 回归、19 项原生 Go 顶层测试及 10 项相关 UI 测试通过；双原生编译、双 HAP 编译、版本/实际链接内核/包内库哈希/Deflate 校验通过。
- 这些是相关测试，不是全量测试通过声明。旧导航拖动 fixture 缺少 `selectNavigation` 的两项失败在日志修改前源码中也可复现。
- 当前手机仍为 0.90.21 Beta；0.90.23 尚未经用户签名覆盖安装，日志手势、真实 SIM/4G/5G 切换和长期后台稳定性仍需真机验证。
- 旧版在 Wi-Fi、VPN 开启时实际 HTTPS 页面已能正常加载；HTTP 204 空白页面本身不代表代理失败。这次成功不能证明旧的间歇性 Wi-Fi 故障或所有 VPN 掉线已根治。
- 不宣称 IPv6/WebRTC 泄漏已全部解决；不宣称所有网络切换、所有页面或长期后台稳定。

## 安装

HAP 未签名，稳定版与 Beta 包名不同。升级须用原签名覆盖安装同一渠道，勿卸载或清除数据；跨渠道不是同一份应用数据。发布附件包含 HAP、完整对应源码 ZIP、构建清单和 SHA256 校验值。
