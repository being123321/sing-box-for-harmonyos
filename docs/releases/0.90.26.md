# 0.90.26 / 0.90.26 Beta

本次只发布最新 0.90.26 稳定渠道与 0.90.26-beta 测试渠道；0.90.24、0.90.25 为未公开中间版本，不单独创建 Release，也不删除已有公开版本。以下汇总自上次公开版本 0.90.23 以来的最终改动。

稳定版 0.90.26 使用 sing-box 1.14.4，Beta 版 0.90.26-beta 使用 1.15.0-alpha.13；两渠道 versionCode 均为 1000135。渠道由包内上游内核决定，本次未升级上游内核版本。

## 切网与配置切换（0.90.24）

- Wi-Fi/蜂窝、默认 SIM、接口或地址变化时保留已有系统 VPN 和 TUN，仅重置旧网络连接；DNS-only 变化只刷新内核解析/HTTP 缓存，不关闭全部连接。
- 当前系统 TUN 地址和双栈默认路由固定，不依赖物理 SIM 地址；仍保留完整双栈接管。
- 策略组节点立即选中，内核 selector 更新后刷新解析缓存，不重建 TUN/VPN。
- 配置切换先验证、应用配置保存的节点和模式；OS VPN 参数相同则热加载内核并继续使用原 TUN，系统参数实际改变时才重建 TUN。失败恢复旧配置与模式。
- SSID 挂起继续停止代理并释放 TUN；挂起期间换配置只保存下次使用的配置。SSID 直连继续经过内核并应用临时直连模式。
- 真实系统 VPN 丢失、明确停止/启动及必要参数变化仍可重建；热加载仍可能分配新的内核资源，不代表所有掉线已根治。

## 排序、批量操作与日志（0.90.25-0.90.26）

- 日志向上滚动固定级别菜单，向下滚动恢复标题；按需连接编辑区位于规则下方。
- 配置和节点支持左侧六点拖动排序，基础配置固定第一；节点左滑编辑/分享，长按多选，支持一次确认批量复制和统一编辑。
- 0.90.26 在拖动时显示整行卡片跟随预览，源位置淡化、目标位置高亮，松手后带排序过渡动画；拖动排序不切换 VPN 或重启内核。
- 按需连接新增/编辑 SSID 的区域移到所有规则下方，打开后自动滚动到底部。

## 自动本地/直连网络 DNS（0.90.25）

- 设置新增“自动获取运营商 DNS”，默认关闭。仅替换本地/直连 DNS，代理 DNS 和保存的原始 JSON 保持原配置。
- 开关改变时热加载；网络提供的 DNS 改变时动态刷新，不额外重建 TUN。

## 保留的既有修复

- 保留 0.90.23 的默认数据网络识别、按需等待、日志卡片身份修复和临时监测移除。
- 保留 0.90.17 之前的透明叠放、页眉、Tailscale 单视图和底部避让。
- 保留 VPN 健康检查、系统内存压力响应、自动恢复、测速和 WebRTC 检测。

## 内核与构建

- 本次 UI 修改复用已验证的原生内核，未重编或升级内核。
- HAP 内 strip 核心 SHA256：稳定 `7542a96f5aadc276ba9c918fd8980cc0e9f2399418f8d07685af20c56272cb37`，Beta `a8a973beddcf5fed8b7fce87d586a0636767f7959ec4ad799cf90bcda0d7a360`。
- 双 HAP 构建、实际库哈希和 Deflate 压缩校验通过；未签名 HAP 哈希见 BUILD-MANIFEST.json，签名后哈希会变化。

## 验证与限制

- 0.90.26 的 15 项相关域/控制器回归通过；0.90.25 记录 75 项相关回归和 22 项 Go 策略测试通过。这里是相关测试，不是全量测试通过声明。
- 历史全量测试仍有未通过项；未逐项归因。
- 0.90.26 尚未签名装机，六点拖动跟随、排序动画、实际运营商 DNS、SIM/4G/5G 切换和长期后台稳定性均待真机复测。
- 不宣称所有 VPN 掉线、低内存、IPv6 或 WebRTC 问题已根治。

## 安装

HAP 未签名，稳定版与 Beta 包名不同。升级须用原 HoKit 签名覆盖安装同一渠道，勿卸载或清除数据；跨渠道不是同一份应用数据。附件包含两个 HAP、各渠道完整对应源码 ZIP、构建清单和 SHA256 校验值。
