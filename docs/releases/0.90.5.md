# 0.90.5

本次汇总自0.83.15以来未发布的改动，只发布当前最新版本。

## 界面和背景

- 页眉、导航及启动栏恢复0.83.15之前的玻璃风格，Clash策略组恢复独立弹层，避免应用底部导航覆盖面板。
- 导航选中图标和文字放大10%，160ms平滑过渡，支持滑动预选；菜单栏位和触控区域尺寸不变。
- 主题新增12种单色、自定义RGB颜色和本地JPG/PNG/WebP背景；设置持久保存，可恢复默认渐变。
- 主题页面修正顶部遮挡和滚动冲突，增加底部留白。

## 节点与按需连接

- 长按节点进入多选，拖动手柄时虚化背景并显示目标配置；复制保留源节点，配置手柄用于上下排序。
- 复制先确认保存；订阅配置再选择允许更新覆盖或保留新增节点。选择保留后，更新订阅会合并新增节点及依赖。
- 相同节点不重复写入，同名不同内容可覆盖或自动加后缀；批量取消后不再复制剩余节点。
- 每个SSID单独选择挂起或直连。挂起关闭VPN及内核，直连保留内核和过滤；恢复不覆盖用户保存的节点和模式。

## 资源与恢复

- 内核成功停止、启动失败回滚及空闲配置校验后回收空闲Go内存；设置512MiB的Go内存软目标，不是进程RSS硬上限。
- 连续恢复失败后冷却再进行有限重试，不再永久停止自动检查。没有可用物理网络时先等待，不消耗恢复次数或反复创建新内核和网卡。
- 保留手动停止、SSID挂起和其他VPN不抢占等优先级。
- 移除VPN运行监控页面、系统事件订阅和专用诊断写入；必需的运行状态通信和自动恢复保留。

## 安装与验证

- 稳定版：0.90.5，内核1.14.4；Beta：0.90.5-beta，内核1.15.0-alpha.13。渠道由上游内核版本区分；versionCode1000114。
- HAP未签名，已内部压缩；使用原签名覆盖安装同一渠道，不要卸载或清除数据。稳定和Beta包名不同，分别保存数据。
- 29项相关逻辑测试、两版编译和压缩校验通过；不代表全套测试或长期真机测试全部完成。
- 新材质、动画、背景图片及真实手势待签名装机确认。系统杀掉整个扩展进程仍可能导致掉线；未宣称彻底解决VPN断联或IPv6/WebRTC泄漏。
- 每个渠道附完整对应源码ZIP、构建清单和SHA256校验值。
