# 0.90

- 主题设置新增12种单色背景：纯白、雾灰、米杏、浅粉、薰衣草、晴空、薄荷、湖青、石墨、深蓝、墨绿、纯黑。
- 支持输入自定义 RGB 颜色（#RGB／#RRGGBB）。选择单色后自动匹配浅色或深色界面，仍可手动切换主题。
- 支持选择本地 JPG、PNG、WebP 背景图片，复制到应用私有目录，重启后继续使用；图片限制16MB、1600万像素，避免过大的图片造成资源压力。提供默认渐变恢复选项。
- 移除 VPN 运行监控页面、菜单、系统退出事件订阅和专用诊断记录写入。运行状态通信和自动断线恢复仍保留。不会再生成专用监控记录，旧版已保存记录未主动清除。
- 延续0.83.24冷却重试及无可用物理网络时等待的恢复策略，延续节点多选、复制和订阅更新保留节点功能。

验证：29项背景输入校验、路径校验、恢复、节点保留、拖动及前台恢复测试通过。稳定和Beta压缩HAP编译通过。背景图片选择、真实拖动及长期后台效果仍待装机验证。
