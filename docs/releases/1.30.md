# 1.30 / 1.30 Beta

本次只发布最新 1.30 稳定渠道与 1.30-beta 测试渠道；1.10、1.20 等中间版本不单独创建 Release，也不删除已有公开版本。以下汇总 1.30 的最终状态。

稳定版 1.30 使用 sing-box 1.14.4，包名 `com.harmonynet.assistant`；Beta 版 1.30-beta 使用 1.15.0-alpha.13，包名 `com.harmonynet.assistant.beta`。两渠道 versionCode 均为 1000152。渠道由包内上游内核决定，本次未升级上游内核版本。

## VPN 与后台传输

- VPN 隧道继续由 `NetworkVpnExtAbility` 持有；后台传输任务移到 `TempAbility`。
- 传输任务不再承担 VPN/TUN 所有权，后台任务生命周期与隧道连接分离，减少传输任务重建或退出对 VPN 的影响。
- 保留有界自动恢复、手动停止优先、系统 VPN 丢失重建和正常健康检查；不宣称进程被系统强制终止后仍可后台自启。

## DNS 与配置

- 使用配置自身的 DNS 策略，不再自动注入运营商 DNS 或国内 DNS 规则。
- 代理 DNS 和用户保存的原始 JSON 保持原配置；不再通过旧参数改写输出。
- 删除旧版内置配置及其生成的本地副本、节点移动，以及工具和设置中的旧 Configuration 入口。
- 现有配置、手动节点、模式和界面设置仍按原有存储保存；升级不自动恢复用户已删除的按需规则。

## 保留的既有修正

- 保留策略组事件订阅、VPN 有界恢复预算、系统内存压力回收、透明叠放/页眉、日志滚动和底部避让。
- 保留节点批量编辑/复制、六点拖动排序及跟随动画、SSID 挂起/直连和配置切换保留 TUN 的既有实现。
- 中间版本的功能已并入 1.30，不逐个发布；不以本说明替代历史版本的完整记录。

## 内核与构建

- 稳定和 Beta 原生核心重新编译；HAP 内 strip 核心 SHA256：稳定 `04d4fa8c3efe55ab451143cec97d363a8b07ca1930376a2bc4a1603bfb602b18`，Beta `00c24280dde26b95ced4ca5e828480e9a41bca3c89a932fae0bdab068569ebbd`。
- 未 strip 核心、包内库和未签名 HAP 哈希见 BUILD-MANIFEST.json；签名后 HAP 哈希会变化。
- 双 HAP 构建、实际库哈希和 Deflate 压缩校验通过。

## 验证与限制

- 98 项相关测试在共享应用源码上通过；未完成全量测试，历史全量测试仍有未通过项。
- 本次未做签名真机验证：VPN 隧道归属、后台传输、DNS 行为、移除旧内置配置后的升级路径及长期后台稳定性仍需原签名覆盖安装后复测。
- 不宣称所有 VPN 掉线、低内存、IPv6 或 WebRTC 问题已根治。

## 安装

HAP 未签名，稳定版与 Beta 包名不同。升级须用原签名覆盖安装同一渠道，勿卸载或清除数据；跨渠道不是同一份应用数据。附件包含两个 HAP、各渠道完整对应源码 ZIP、构建清单和 SHA256 校验值。
